# Linux debugger

Learn how to implement a linux debugger in C/C++ language.

## Features supported

- [x] launch, halt and continue e ecution
- [ ] set breakpionts on
  - [x] memory addresses
  - [ ] source code lines
  - [ ] function entry
- [ ] read and write registers and memory
- [ ] single stepping
  - [ ] instruction
  - [ ] step on
  - [ ] step in
  - [ ] step out
- [ ] print current source location
- [ ] print backtrace
- [ ] print values of simple variable
